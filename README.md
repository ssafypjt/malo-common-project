# MALO — 말로 만드는 개인 투자 전략

> 자연어로 투자 조건을 만들고, 확인한 전략을 모의 환경에서 실행하는 개인 투자 도구

MALO(My Agent for Linked Orders)는 사용자가 일상 언어로 입력한 투자 조건을 실행 가능한 규칙으로 정리하고, 검토·승인한 전략을 모의투자 환경에서 감시하고 실행하는 서비스입니다. 전략을 만드는 과정과 실행 상태를 한 화면에서 이해할 수 있도록 설계했습니다.

## 프로젝트 개요

| 항목 | 내용 |
| --- | --- |
| 프로젝트 | SSAFY 15기 2학기 공통 프로젝트 |
| 분야 | 핀테크 · AI 기반 서비스 |
| 핵심 경험 | 자연어 조건의 규칙화, 전략 검토·승인 흐름, 모의투자 실행 |
| 실행 환경 | 사용자 PC에서 구동하는 로컬 웹 서비스 |

## 해결하고자 한 문제

투자 아이디어를 반복 가능한 조건으로 옮기려면 가격, 수량, 시점, 실행 방식 등을 명확히 정의해야 합니다. MALO는 사용자가 말로 표현한 조건을 구조화된 전략 초안으로 보여주고, 직접 확인하고 수정한 뒤 승인할 수 있도록 했습니다. 승인된 전략은 AI 응답에 의존하지 않고 별도의 실행 엔진이 관리합니다.

## 주요 기능

1. **자연어 전략 작성** — 대화로 입력한 투자 조건을 규칙 초안으로 변환합니다.
2. **전략 검토와 승인** — 조건과 실행 내용을 확인·수정한 뒤 전략을 등록합니다.
3. **백테스트** — 과거 데이터를 바탕으로 전략의 결과를 살펴봅니다.
4. **모의투자 감시·실행** — 가상 잔액과 자체 체결 판정을 사용해 승인된 전략의 상태를 추적합니다.
5. **실시간 시세와 계좌 화면** — 시세, 모의 계좌, 전략 카드를 한 화면에서 확인합니다.

> 현재 구현 범위는 **모의투자**입니다. 실제 자금으로 주문하는 기능은 포함하지 않습니다. 전략 감시와 실행에는 사용자 PC가 켜져 있어야 합니다.

## 서비스 흐름

```text
자연어로 조건 입력 → 전략 초안 생성 → 조건 확인·수정 → 사용자 승인
                                                  ↓
                              백테스트 및 모의투자 감시·실행
                                                  ↓
                                  전략 상태와 결과 확인
```
